# Panorama prototype

One isolated, map-first Votus landing overview using the approved navy/cyan/Plex
design. It answers where the selected territory stands and where to continue an
analysis, without repeating the deeper tools. User-approved single design; no
variants, application changes, live database/auth query or production promotion.

## Run and verify

From this directory, run `node serve.mjs` and open the printed loopback URL.
The parent-owned verification entry points are `node verify.mjs` and
`node verify-server.mjs`. No installation or database test command is required.
Strict TDD is enabled by project AGENTS.md rule 11. The parent observed the real
HTTP entry returning 404 before any candidate source was created.

## Reused read-only inputs

The server proxies the immutable Exploration demonstration fixture, geographic
references and local Plex fonts. The thin Panorama model imports the immutable
Evidence validator/coverage/geometry helpers and Simulation party registry. None
of those existing prototypes is written or copied into this candidate.

All numerical results, coverage and grouping names are fictional. The default is
Argentina, 2025, national deputies. Overview navigation stops at country,
province and PBA partido: 160 nodes. The 14 fictional Rosales deep units remain
in Exploration only. Other provinces have no inferred child detail.

## Interpretation boundaries

- Shares and margins use the sum of all four positive-vote values, never turnout,
  electorate or an expected official denominator.
- A partial vector has a provisional leader, not a definitive winner. Ties, zero
  vectors and missing vectors remain distinct; no identifier-based winner.
- Party map fill requires a complete, positive, unique first place and a valid
  reference geometry. Observed shapes are retained neutral. All 24 provinces/CABA
  and 135 partidos remain reachable through the native searched/paginated list.
- Geometry is independent of data availability and does not establish historical
  electoral equivalence. The source continental frame and separate neutral polar
  reference are preserved. No deep polygons or school/mesa locations are invented.
- Coverage uses the selected record and structural-unit checks from Evidence.
  Untyped 0/1 records stay untyped, without a percentage. Search/page counts are
  not coverage denominators. The national aggregate is independent of its rows.
- Real-data-not-queried, loading and local asset failure clear former figures and
  observations. No hosted query, credentials, cookie or browser storage is used.
- Deterministic observations describe only the selected demonstration, not a
  forecast, political recommendation, real missing-data cause or confidence score.
- Four deeper-tool links open the verified sibling root URLs in another tab.
  Their initial context is not this selection; the reset is explicitly disclosed.

## Accessibility and delivery limits

Native controls, semantic regions, a named legend, alternative territory lookup,
visible focus, retry focus restoration and a native mobile navigation dialog are
provided. Responsive and automated checks do not certify manual contrast,
screen-reader behavior, physical mobile interaction or all browsers. Functional
verification and final screenshots are parent-owned; this README does not claim
unobserved checks passed. Engram mirroring is pending while the host prohibits
agent-attributed memory tools without an authoritative runtime identity.
